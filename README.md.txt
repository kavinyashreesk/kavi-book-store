# Kavi Book Store

A simple Python Object-Oriented Programming (OOP) project for managing bookstore inventory, customer carts, percentage discounts, and billing.

## Features
- Add and sell book stock with availability checks
- Display book details (`Book ID`, `Title`, `Author`, `Price`, `Quantity`)
- Add books to a customer cart and apply percentage discounts
- Generate itemized bills and automatically update remaining stock

## How to Run
1. Open the project folder in your terminal or code editor.
2. Run the script:
   ```bash
   python main.py
